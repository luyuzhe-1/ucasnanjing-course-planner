# 国科大南京学院选课规划工具

面向 2026–2027 学年秋、春两个学期的可视化选课辅助工具。两个学期可分别选课、统计学分并检查每学期是否达到 10 学分；已有排课信息的课程会按周次、星期和节次显示并自动提示时间冲突。

## 下载离线版

无需安装开发环境，也不需要登录、密码或 VPN：

1. 下载最新版 [`ucasnanjing-course-planner-v1.1.0.zip`](downloads/ucasnanjing-course-planner-v1.1.0.zip)（兼容下载入口仍为 [`ucasnanjing-course-planner-offline.zip`](downloads/ucasnanjing-course-planner-offline.zip)）。
2. 解压整个压缩包。
3. 双击其中的“打开选课系统.html”。

请不要在压缩包预览窗口中直接打开网页，也不要删除或重命名解压后的 `assets` 文件夹。

## 主要功能

- 按课程名称、代码、教师、开课单位、课程属性和培养层次筛选课程
- 在秋季、春季课程目录之间切换，并分别保存选择
- 分别提示秋季和春季距离最低 10 学分要求的差额
- 按第 2–20 周查看课程时间分布
- 检测同一周次、星期和节次上的课程冲突
- 自动统计两个学期的学分和全学年已选学分（不判断全年总学分是否达标）
- 集中查看全部已选课程，并可快速逐门删除
- 将已选课程导出为 Markdown 文件
- 选择结果仅保存在当前浏览器，不会上传

## 双学期版本更新内容

- 纳入 2026–2027 学年计划开设课程总表：秋季 78 门、春季 69 门（均包含 2 门秋春课程）
- 秋季已有 89 个具体开课班、157 条正式上课安排；春季使用 2025–2026 学年春季课表中的同名课程时间作为参考，并在界面与导出文件中明确标注
- 补充限选人数、授课教师、考试方式和授课方式等秋季课程信息
- Markdown 导出新增限选、教师和考试方式，且不包含上课地点
- 新增“管理已选”面板，可集中查看、检查冲突并快速删除课程
- 搜索范围新增英文课程名、授课教师和考试方式

## 数据说明

课程数据整理自：

- 2026 年秋季学期最新课程总览
- 2026–2027 学年计划开设课程总表
- 2025–2026 学年春季学期课表（仅作时间参考）

课表后续如有调整，请以学校最新通知和选课系统中的实际信息为准。

## 本地开发

项目使用 Node.js 和 pnpm。安装依赖后运行：

```bash
pnpm install
pnpm run dev
```

然后访问 `http://localhost:3000/`。
