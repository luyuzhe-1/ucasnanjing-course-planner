# 国科大南京学院选课规划工具

面向 2026–2027 学年秋季学期的可视化选课辅助工具。选择课程后，课程会按周次、星期和节次显示在课表中，并自动提示时间冲突。

## 下载离线版

无需安装开发环境，也不需要登录、密码或 VPN：

1. 下载 [`ucasnanjing-course-planner-offline.zip`](downloads/ucasnanjing-course-planner-offline.zip)。
2. 解压整个压缩包。
3. 双击其中的“打开选课系统.html”。

请不要在压缩包预览窗口中直接打开网页，也不要删除或重命名解压后的 `assets` 文件夹。

## 主要功能

- 按课程名称、代码、开课单位、课程属性和培养层次筛选课程
- 按第 2–20 周查看课程时间分布
- 检测同一周次、星期和节次上的课程冲突
- 自动统计已选课程数量和总学分
- 本地网页支持将已选课程导出为 Markdown 文件
- 选择结果仅保存在当前浏览器，不会上传

## 数据说明

课程数据整理自：

- 2026–2027 秋季学期课表（按星期）
- 2026–2027 学年计划开设课程总表

课表后续如有调整，请以学校最新通知和选课系统中的实际信息为准。
